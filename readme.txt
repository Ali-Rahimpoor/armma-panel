پنل کاربری پیشرفته و ماژولار ووکامرس: ورود/ثبت‌نام با شماره موبایل و OTP، تیکتینگ، گردونه شانس، علاقه‌مندی‌ها و پیامک پترن.

== Description ==

آرما پنل جایگزین کامل «حساب کاربری» ووکامرس است:

* ورود و ثبت‌نام با شماره موبایل ایران + کد یک‌بار‌مصرف (OTP) با هش bcrypt
* پنل مشتری با داشبورد، سفارش‌ها، تیکت‌ها، نشانی‌ها، اطلاعیه‌ها و علاقه‌مندی‌ها
* گردونه شانس پس از خرید (کد تخفیف اختصاصی، تک‌کاربردی و شخصی برای هر برنده)
* یادآوری سفارش‌های پرداخت‌نشده با کد تخفیف اختصاصی
* پیامک پترن با پشتیبانی از چند سرویس (ملی‌پیامک، کاوه‌نگار، SMS.ir، فراز اس‌ام‌اس)
* سازگار با HPOS (جدول‌های سفارش اختصاصی ووکامرس)

== Installation ==

1. پوشه افزونه را در `wp-content/plugins` بارگذاری کنید (نیاز به ووکامرس فعال).
2. افزونه را از منوی «افزونه‌ها» فعال کنید؛ صفحه پنل و جداول به‌صورت خودکار ساخته می‌شوند.
3. از «آرما پنل ← تنظیمات» سرویس پیامک و پترن‌ها را پیکربندی کنید.

== Frequently Asked Questions ==

= آیا برای استفاده، ووکامرس لازم است؟ =

بله؛ این افزونه هدر `Requires Plugins: woocommerce` دارد و بدون ووکامرس فعال نمی‌شود.

= آیا با HPOS سازگار است؟ =

بله؛ سازگاری `custom_order_tables` در `before_woocommerce_init` اعلام شده و همه متای سفارش‌ها از طریق API سفارش ووکامرس خوانده/نوشته می‌شود.

= صفحه پنل با آدرس `/arma-panel/` باز نمی‌شود یا خطای ۴۰۴ می‌دهد. چه کنم؟ =

پس از فعال‌سازی، یک‌بار «تنظیمات ← پیوندهای یکتا» را ذخیره کنید تا قواعد بازنویسی ساخته شوند. اگر افزونه کش (مثل LiteSpeed Cache یا WP Rocket) دارید، صفحه پنل (`/arma-panel/` و زیرصفحه‌های آن) و آدرس `admin-ajax.php` را از کش مستثنا کنید؛ کش شدن این آدرس‌ها باعث خرابی ورود با پیامک و به‌روزنبودن صفحات پنل می‌شود.

= کوپن «ارسال رایگان» گردونه شانس در سبد خرید اعمال نمی‌شود. چرا؟ =

کوپن ارسال رایگان فقط وقتی کار می‌کند که روش حمل «ارسال رایگان» در ووکامرس فعال باشد. از «ووکامرس ← تنظیمات ← حمل و نقل» یک روش ارسال «ارسال رایگان» اضافه کنید و شرط آن را «کوپن با ارسال رایگان» بگذارید؛ سپس در سبد خرید، این روش را انتخاب کنید تا کوپن هزینه ارسال را صفر کند.

= کدام کاربران می‌توانند با پیامک (OTP) وارد شوند؟ =

به‌طور پیش‌فرض فقط حساب‌های با نقش «مشتری (customer)» و «مشترک (subscriber)». حساب‌های مدیریتی (مدیر کل، مدیر فروشگاه، ویراستار) به‌هیچ‌وجه اجازه ورود با پیامک ندارند. فهرست نقش‌های مجاز از «آرما پنل ← تنظیمات ← ورود و ثبت‌نام» قابل تغییر است.

= اگر افزونه را حذف کنم، داده‌ها پاک می‌شوند؟ =

خیر؛ به‌طور پیش‌فرض هنگام حذف افزونه فقط داده‌های موقت (transient) و زمان‌بندی‌های خودکار پاک می‌شوند و جداول، تنظیمات، شماره موبایل کاربران و متاهای سفارش دست‌نخورده می‌مانند. حذف کامل داده‌ها فقط با فعال‌کردن گزینه هشداردهنده «حذف کامل داده‌ها هنگام حذف افزونه» در تنظیمات عمومی انجام می‌شود.

= اطلاعات پیامکی که ذخیره می‌کنم امن است؟ =

بله؛ نام کاربری/رمز و کلید API سرویس پیامک با رمزنگاری AES-256-GCM و کلید مشتق‌شده از نمک‌های `wp-config.php` در پایگاه داده ذخیره می‌شود. اگر نمک‌های سایت را تغییر دهید، افزونه در تنظیمات پیامک هشدار می‌دهد و تا وارد کردن دوباره اطلاعات، ارسال پیامک متوقف می‌شود.
